# Workspace Project Rules

## Component Showcase Standards
- Keep components modular and self-contained with dedicated CSS modules.
- Ensure cross-browser CSS mask support (`-webkit-mask-*` and standard `mask-*`).
- Maintain working sticky scroll calculations without placing `overflow: hidden` on root ancestors (`html`/`body`).
- For `staggered-grid-animation`, preserve user image mappings (`ditther-1.png` to `ditther-21.png`), exact reference copywriting, `max-width: none` on `.grid--full`, and hidden navbar header frame.
- For `dashboard`, strictly follow the **Slush Light Mode** design system (`#dceeff` Sky Wash, `#000000` Carbon hand-cut outlines, `#55db9c` Mint Pop, `#ffd731` Sunburst, `#4da2ff` Electric Blue, 1600px pill buttons, sticker star markers `★`, zero drop shadows/glows).
- All 282 unique component packages are organized inside 13 category folders (`3D Animation` [23], `Background Animations` [11], `Grid Animations` [10], `Hero Animations` [26], `Hover Effects` [21], `Mouse Effects` [21], `Navigation Menus` [21], `Page Transitions` [14], `Physics Effects` [10], `Sliders` [23], `SVG Animations` [11], `Webgl & ThreeJS Effects` [19], `Scroll Animations` [66]) plus 6 unique standalone top-level labs (`text-mask-animation`, `staggered-grid-animation`, `flower-image-animation`, `pixel-image-animation`, `buildloom portfolio`, `buildloom-vite-template`).
- Official Buildloom Documentation reference: `https://buildloom.github.io/docs/index.html`.
